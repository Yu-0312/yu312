關於這個站

這是 Yuqi 的個人入口站：柔和背景、毛玻璃圓角卡片、側邊導覽與分享卡片，整個站都是純靜態網頁。

站內功能

  • 首頁：依時段問候、即時時鐘、當月月曆、最新文章、隨機推薦、社群連結、專注模式與點讚小玩具
  • 推薦分享：資源卡片，可依分類篩選、也可用關鍵字即時搜尋
  • 我的專案：專案卡片整理，依星數排序

怎麼換成自己的內容

  • 文字資料都在 site.js：SHARE_ITEMS（推薦卡）與 PROJECT_ITEMS（專案卡），改陣列內容就會跟著更新
  • 首頁的最新文章與問候文字寫在 index.html
  • 頭像、游標、favicon 都是 assets/ 裡的 SVG，直接換檔即可
  • 改完存檔、重新整理就生效，不需要任何建置工具

技術小記

  • HTML / CSS / JavaScript 手工撰寫，沒有框架、沒有追蹤碼
  • 沒有任何對外請求：字型檔與插圖都隨站打包，離線也能開
  • 支援鍵盤導覽與 prefers-reduced-motion 偏好
